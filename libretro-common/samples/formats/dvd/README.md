# Native DVD packet views

`rdvd_packet_read` consumes private-stream PES payloads from `rmpeg1_ps_next`.
It returns borrowed elementary payload spans, substream IDs, DVD audio header
metadata, and DVD-Video LPCM configuration. `rdvd_nav_read` reads the general
information of complete PCI/DSI records using explicit big-endian loads.

No FFmpeg, libdvdread or libdvdnav headers or libraries are used. The test's
optional VOB fixture is generated by an external FFmpeg executable; it is not
an application dependency.

These readers do not assemble SPU units, decode audio/video, interpret IFOs,
execute VM commands, render menus or decrypt discs. Audio access-unit pointers
retain their DVD wire value; consumers must interpret their origin before
using them as offsets. Borrowed spans expire with the originating PES input.
LPCM accepts DVD-Video's 48/96 kHz and 16/20/24-bit configurations; DVD-Audio
AOB formats are outside this API.

Run `make check SANITIZER=address,undefined` for exhaustive header/truncation
tests, whole/split/bytewise PES input, borrowed pointer identity, timestamp
damage recovery and NAV general fields. `make CC=x86_64-w64-mingw32-gcc
EXE=.exe all` builds the same tests for Windows.

An optional generated DVD fixture must contain MPEG video, AC-3 and PCI/DSI:

```sh
ffmpeg -f lavfi -i color=size=720x576:rate=25 \
  -f lavfi -i sine=sample_rate=48000 -t 0.4 \
  -c:v mpeg2video -b:v 2000k -c:a ac3 -ac 2 -ar 48000 -f dvd fixture.vob
./rdvd_packet_test fixture.vob
```

Format references checked for this implementation:

- [ITU-T H.222.0, MPEG systems](https://www.itu.int/rec/T-REC-H.222.0-202308-S)
- [FFmpeg MPEG demux format handling](https://github.com/FFmpeg/FFmpeg/blob/master/libavformat/mpeg.c)
- [FFmpeg DVD LPCM header fields](https://github.com/FFmpeg/FFmpeg/blob/master/libavcodec/pcm-dvd.c)
- [Published NAV wire layouts](https://github.com/xbmc/libdvdread/blob/master/src/dvdread/nav_types.h)

References describe wire fields; this implementation does not include or call
the referenced libraries.
