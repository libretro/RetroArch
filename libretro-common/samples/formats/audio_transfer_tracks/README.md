# Container audio track selection

`make check` tests real MP4 AAC and Matroska AAC/Opus/Vorbis/FLAC tracks.
Every fixture has a video track at index zero and independently encoded
440/880 Hz mono tracks at 48 kHz. The mixed fixture uses four different audio
codecs. The test measures both frequencies in decoded PCM, including after
seek, and refuses wrong-codec, video, missing and oversized track requests.
It also checks resident-prefix admission and refusal to mutate an active decoder.
FLAC seeks through 2400 frames without a scratch PCM buffer, then requires the
exact remaining frame count and correct float-output tone.

Fixtures are synthetic and generated by `generate.py --ffmpeg FFMPEG`; no
copyrighted media is included. Generation used the native-listener Windows
FFmpeg 2025-12-07 build. Tests consume checked-in fixtures and need no external
encoder. Container metadata/codec revisions can make regenerated bytes differ;
the independent frequency and lifecycle assertions remain the oracle.

The default production build treats frames over 2048 bytes as errors. Sanitizer
builds retain frame warnings: instrumented legacy AAC/Vorbis/CPU-discovery frames
exceed this limit although the normal production build passes. Run both the
normal and sanitizer checks; an instrumentation warning is not a production
stack-budget pass. This sample supplies decoder selection, not a completed
frontend audio-track UI.

`make check` also runs the mixer integration test. Both float and S16 paths
must play the requested 440/880 Hz track through repeats, including codec
changes within the mixed container. Legacy automatic loads remain covered.
A prepared decoder with the wrong track or output format is refused without
consuming it; a matching prepared decoder is adopted once. Every sound's
borrowed source owner is released exactly once after voice retirement.
These mixer factories do not add a frontend menu control by themselves.
